## 🧹 2. Data Cleaning & Preparation

The following data cleaning and preparation activities were performed:

- Identified and handled duplicate records.
- Checked for missing or inconsistent values.
- Standardized column names and data formats.
- Corrected date and numerical data formats.
- Checked consistency in categorical values.
- Organized the dataset into a structured Excel table.
- Created useful calculated fields such as Month, Quarter, Year, and Sales.
- Verified numerical columns such as Quantity, Discount, Rating, Unit Price, and Cost.
- Prepared the cleaned dataset for further analysis and dashboard creation.
